# ПриЕм · Хэллоуин — мини-игра «Найди ПриЕм»

Спецблок для Тильды (экран 2 спецлендинга): жутковатая кухня, 6 светящихся предметов, в одном случайном спрятан промокод **СТРАШНОВКУСНО** (−777 ₽ на заказы от 5 дней). Остальные экраны лендинга делает админка сайта — здесь только игра.

Превью: https://elenasamanchuk.github.io/priem-halloween-game/

## Вставка на Тильду

1. Откройте `dist/halloween-game-tilda.html`, выделите всё и скопируйте.
2. На странице Тильды добавьте **один** блок T123 «HTML-код» между первым экраном и меню, вставьте код, сохраните и опубликуйте.
3. Кнопке «Я ничего не боюсь» на первом экране поставьте ссылку `#halloween-game` — будет плавный скролл к игре.
4. «Смело заказать ПриЕм с выгодой» ведёт на `#menu-plans-v2` (блок меню/заказа на странице).

Блок работает и на самой Тильде, и внутри priem.menu, где страница Тильды подставляется через innerHTML (скрипт запускается «маячком», как в мемо-игре). Без iframe. Картинки — с jsDelivr, ссылка закреплена на коммит.

## Что где менять

Всё в `HLW_CONFIG` в начале `scripts/build.mjs`, потом `node scripts/build.mjs`:
- тексты попапов, кнопок, счётчика; 8 текстов промаха и какая иллюстрация к какому;
- промокод, ссылка заказа, **ссылка для шеринга** (`links.shareUrl` — сюда ссылку с `?cmz=…`);
- `ymId` — номер счётчика Метрики (цели `hlw_start`, `hlw_miss`, `hlw_win`, `hlw_copy_code`, `hlw_order_click`, `hlw_share_click`, `hlw_sound`); события в любом случае уходят в `dataLayer`.

## Графика

Источник — Figma «Иллюстрации (Copy) (Copy)», страница «Ноябрьская охватка». Исходники лежат локально в `assets-src/` (в git не попадают).
- `python3 scripts/match-items.py .` — находит, где вырезка предмета лежит на кадре кухни (OpenCV), пишет `assets-src/items/positions.json`;
- `python3 scripts/prepare-assets.py` — WebP с хешем в имени + `assets/manifest.json` (координаты для деска и мобильного);
- после смены ассетов: закоммитить `assets/`, затем `node scripts/build.mjs` (ссылка CDN закрепится на этот коммит) и закоммитить `dist/`.

## Как устроено

- Деск (≥1024): кадр макета — пещера и окно кухни; <1024: только окно кухни во всю ширину.
- Предмет = светящаяся вырезка поверх такого же предмета на фото: свечение «дышит», проверенный предмет гаснет.
- Рандом при каждой загрузке: предмет с промокодом и тексты промахов (иллюстрации за игру не повторяются).
- Эффекты: пыль и угольки (canvas, 30 к/с в простое), туман, мерцание лампы, дым при промахе, золотые искры при победе. Всё останавливается вне экрана; `prefers-reduced-motion` учитывается.
- Звук: WebAudio-синтез, без файлов; выключен по умолчанию, включается кнопкой; фон — музыкальная шкатулка.
